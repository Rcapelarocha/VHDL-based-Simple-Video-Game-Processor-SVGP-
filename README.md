# VHDL-based-Simple-Video-Game-Processor-SVGP-
A VHDL-based Simple Video Game Processor (SVGP) implemented on a Xilinx Spartan-3E FPGA, capable of generating real-time VGA output for a Pong-style game. Includes custom VGA timing generation, pixel-level rendering, paddle and ball motion logic, and collision/goal detection. Developed for COE758 — Digital Systems Engineering.
